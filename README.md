# ResumeDocs

厚生労働省の「履歴書様式例」どおりの履歴書をブラウザで作って PDF にし、応募先ごとの選考の進み具合と面接の記録も残せるツールです。

**[ブラウザで使う](https://resume-docs.com)**（無料・登録不要。入力した内容はブラウザの中だけに保存し、どこにも送りません）

## できること

### 履歴書

- **公式の様式そのまま**：厚生労働省が配布している PDF を下地にして、記入内容だけを重ねます。罫線も見出しも描き直していないので、様式は公式と同じです（罫線の位置が 0.01pt 以内で一致することを `check_form.py` で確かめられます）
- **スマホだけで完結**：入力、プレビュー、PDF の保存までスマホでできます。保存すると共有メニューが開くので、そのままファイルに保存したり、LINE やメールで送ったりできます
- **いくつでも保存**：履歴書はいくつでも保存でき、フォルダで分けられます。応募先ごとに複製して、志望動機だけ書き換える、といった使い方ができます。一覧では、それぞれの履歴書でまだ書いていない項目が分かります（例：「未入力：志望動機」）
- **入力の手間を減らす**：郵便番号と電話番号にはハイフンが自動で入り（電話番号は国番号も選べます）、メールアドレスは gmail.com などの候補から選べます。学歴・職歴・資格は、年月の順に自動で並びます
- **欄からはみ出さない**：長い文章は、欄に収まるまで文字を小さくします。行数が様式を超えたときは知らせるだけで、勝手に切り捨てません
- **A4 と A3**：A4（2枚）と A3（見開き1枚）のどちらでも保存でき、顔写真も入れられます

### 選考管理

- **応募先ごとに1件**：会社名、選考の段階（応募前・書類選考・面接・内定・終了）、送った履歴書、会社についてのメモをまとめておけます
- **面接ごとの記録**：カジュアル面談、一次面接、二次面接、最終面接などを1回ずつ記録し、日付とメモを残せます。メモは入力したそばから保存されます
- **次の予定が分かる**：一覧には、それぞれの応募先の次の面接の日付が出ます
- **履歴書とつながる**：応募先の画面から、送った履歴書をそのまま開けます

## 使い方

1. [ResumeDocs](https://resume-docs.com) を開いて「履歴書をつくる」を押す（試すだけなら「見本で試す」）
2. 基本情報・現住所・学歴・職歴などを入力する。パソコンでは画面の右側、スマホでは「プレビュー」で仕上がりを確認できる
3. 「PDF を保存」を押す

作った履歴書は「保存した履歴書」に並び、次からはトップの右上から開けます。スマホでホーム画面に追加すると、この一覧から開きます。

選考管理は、一覧の「選考管理」タブ（スマホでは画面の下、パソコンでは右上）から開き、「応募先を追加」で始めます。

### 知っておいてほしいこと

- **データはそのブラウザの中だけにあります。** ブラウザのデータを消すと、履歴書も選考の記録も消えます。残しておきたいときは、ファイルに書き出してください。書き出したファイルは、別の端末でも読み込めます
  - 履歴書：編集画面のメニューの「データを書き出す」で書き出し、一覧の「新しく作る」の ▾ にある「ファイルから読み込む」で読み込む
  - 選考管理：一覧の右上のメニューの「書き出す」「読み込む」を使う
- 作れるのは履歴書だけです。職務経歴書は、下の「コマンド版」で作れます
- 写真は JPEG か PNG を使ってください（Chrome では iPhone の HEIC 形式を読めません）
- 初回だけ、PDF 用のフォント（約 7.8MB）の読み込みに少し時間がかかります

## コマンド版（職務経歴書も作れる）

経歴を TOML ファイル1つにまとめておくと、履歴書（A4・A3）と職務経歴書を PDF で出力します。職歴は、履歴書の学歴・職歴欄と職務経歴書の両方に入ります。必要なのは Python 3.11 以上と Google Chrome だけです（pip install は不要）。

![出力例（A3 版）](docs/sample.png)

```sh
git clone https://github.com/6igtree/career-hub.git
cd career-hub
python3 build.py    # career.toml がなければサンプルで生成する
```

自分の経歴で作るときは、サンプルをコピーして編集します。`career.toml` は `.gitignore` に入っているので、うっかりコミットされることはありません。

```sh
cp career.example.toml career.toml
# career.toml を編集（書き方はファイル内のコメントを参照）
python3 build.py
```

`out/` に次の3つができます（macOS では生成後に開きます）。

| ファイル | 内容 |
| --- | --- |
| `履歴書.pdf` | A4 版（2枚） |
| `履歴書_A3.pdf` | A3 版（見開き1枚） |
| `職務経歴書.pdf` | 職務経歴書 |

Chrome が見つからないときは、環境変数 `CHROME` に実行ファイルのパスを指定してください。

### 顔写真

`career.toml` の `[profile]` にある `photo` に画像のパスを書くと、写真欄に入ります。

```toml
photo = "photo.jpg"   # career.toml からの相対パス
```

- 写真欄いっぱいに表示し、縦横比が合わない分は中央で切り取ります。縦4:横3 の証明写真データなら、ほぼそのまま収まります
- macOS では iPhone の HEIC もそのまま使えます。大きな写真は長辺 1200px に縮めて埋め込むので、PDF は数百 KB に収まります
- macOS 以外では JPEG か PNG を使ってください（縮小はしないので、大きな写真は先に縮めておきます）
- `photo.*` は `.gitignore` に入っているので、写真がコミットされることはありません

## 様式の決まりに合わせていること

ブラウザ版とコマンド版で共通です。

- 様式にメール欄がないので、メールアドレスは電話欄の下に入れる
- 連絡先欄は、現住所以外に連絡を希望する場合だけ書く（様式の注記どおり）
- 性別は任意。空なら空欄のまま
- 学歴・職歴は22行、免許・資格は6行、本人希望は4行まで
- 公式 PDF の写真欄には「縦／横」の寸法の数字が入っていない。下地は公式のままなので、出力にも入らない

## 開発

### ブラウザ版

`web/` にあります（Next.js と shadcn/ui）。サーバーを持たない静的なページで、入力内容を厚生労働省の公式 PDF に直接書き込みます。文字を置く位置は、コマンド版と共通の `form/layout.json` を使います。

| パス | 画面 |
| --- | --- |
| `/` | 説明のページ（検索に出すのはここだけ） |
| `/app/` | 保存した履歴書の一覧とフォルダ |
| `/edit/?id=…` | 履歴書の入力とプレビュー |
| `/app/applications/` | 選考管理の一覧 |
| `/app/applications/detail/?id=…` | 応募先ごとの選考の記録 |

データはすべて `localStorage` に保存します。履歴書と選考管理は別のキーに持ち、選考管理からは履歴書を id で参照します。

```sh
cd web
npm install
npm run dev     # http://localhost:3000 を開く
```

`npm run build` で、静的なページが `web/out/` に書き出されます。

### 様式の検証

```sh
brew install poppler   # 初回だけ
python3 check_form.py
```

コマンド版でサンプルから作った履歴書の罫線の座標を、公式 PDF と比べます。Chrome は PDF にするときにページをわずかに縮める（A4 で約0.01%、A3 で約0.07%）ので、その分を `style.css` の `.cal` で打ち消しています。Chrome の更新でずれが出たら、このチェックで分かります。

コマンド版の動作を確かめているのは macOS + Google Chrome 155 です。ほかの OS でも動くはずですが未確認なので、使う前に `check_form.py` で確かめてください。
